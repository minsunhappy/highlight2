# Generating Highlight Videos of a User-Specified Length using Most Replayed Data

Official implementation of the paper **“Generating Highlight Videos of a User-Specified Length using Most Replayed Data”**, presented at **CHI 2025**.

**Minsun Kim, Dawon Lee, and Junyong Noh**  
KAIST

[Project Page](https://w-dlee.github.io/highlights) · [Paper](https://doi.org/10.1145/3706598.3713880)

## Overview

Our method automatically generates highlight videos of a user-specified
length using YouTube's Most Replayed Data (MRD). It identifies engaging
moments and optimizes the editing path by adjusting segment durations
to meet the requested video length.
